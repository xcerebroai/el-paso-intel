## general

The operator volunteered no source-specific knowledge during this Phase 0
run (the instruction was a one-sentence "Build El Paso County, Texas").
The notes below are recon-surfaced context, not operator overrides — no
`operator_override_audit` entry was created and none was needed.

- 2026-05-17 — El Paso County is on **Mountain Time** (America/Denver),
  one of only two Texas counties not on Central Time. Every refresh
  cadence, heartbeat staleness window, and first-Tuesday sale-date
  calculation must use Mountain Time. Carried into `timezone` in the
  county config.
- 2026-05-17 — The county migrated its web presence from `epcounty.com`
  to `epcountytx.gov`. Some legacy `epcounty.com` deep links now 404.
  Treat `epcountytx.gov` as authoritative; the record applications live
  on `apps.epcountytx.gov`.
- 2026-05-17 — Wrong-county trap: web searches for "El Paso" foreclosure /
  treasurer surface `elpasopublictrustee.com` and `treasurer.elpasoco.com`,
  which belong to El Paso County, **Colorado**. Texas has no public
  trustee. All Colorado results were discarded during recon.

## parcel_master

- 2026-05-17 — EPCAD (`epcad.org` / `go.epcad.org/search`) returned HTTP
  403 to recon fetches — appraisal-district WAF. Enrichment source, so it
  does not gate the build. EPCAD publishes an Open Government /
  open-records page worth checking in Build Mode for a cleaner bulk path.
- 2026-05-17 — RESOLVED: a documented unauthenticated public JSON API
  exists (EPCAD Property Search API) — see recon/epcad_api_recon.md. The
  WAF applies to the HTML site only. Config updated: parcel_master is now
  access_method API_ENDPOINT, auto_resolve_status RESOLVED.
- 2026-05-17 — EPCAD API pagination probe: the API is SLOW for broad
  pulls (~30s for a 500-record page; a 1000-record page timed out at
  60s). A full-county bulk index (~280k-320k parcels) would be ~600+
  pages and 5+ hours — NOT feasible inline. Per-row enrichment (small
  targeted queries) remains feasible. A standing bulk index must be a
  separate scheduled/offline job.

## foreclosure_notices

- 2026-05-17 — DEFERRED. build_status set to
  `DEFERRED_PENDING_BULK_ENRICHMENT_INDEX` in
  config/counties/el_paso_tx.json. Reason: foreclosure_notices rows carry
  only a legal description (subdivision/lot/block) — no address, owner,
  or parcel id. The EPCAD API has no legal-description / subdivision /
  lot / block search parameter, so foreclosure rows cannot be enriched by
  a direct per-row EPCAD call. Enrichment for this source needs either
  (a) a bulk EPCAD index keyed on parsed LegalDescription to join
  against, or (b) parsing the linked Notice-of-Sale PDFs for street
  address + debtor name, then querying EPCAD by address. Both are
  deferred to a later session. The partial scrape at
  data/el_paso_tx/raw/foreclosure_notices.jsonl (20 records, page 1 only)
  is retained as-is — not deleted, not extended. foreclosure_notices is
  excluded from the 4-source build and from the dashboard until
  re-enabled.
